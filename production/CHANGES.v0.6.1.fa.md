# تغییرات ۰.۶.۱+۸ — کامل‌شدن انتخاب‌گر رنج

## رفع علت، نه تضعیف آمار
- `lib/domain/price_range.dart`: کاتالوگ مستقل `RangeProduct` شامل رنج nullable، برچسب و جستجوی cacheشده و دلایل نبود رنج. کالاهای نامشخص با endpoint/id/unit جدا می‌مانند. همه قواعد مالی و حلقه محاسبه رنج پیشین محفوظ است.
- `lib/data/store.dart`: علاوه بر اعلام‌های۴۸ساعت، همه latest از جمله غیرفعال و نماینده history فاقد latest برای کاتالوگ خوانده می‌شود. ردیف خارج بازه وارد آمار نمی‌شود؛ داده قدیمی تازه‌سازی نشده است. schema۳ و ایندکس‌ها بدون تغییر.
- `lib/ui/range_page.dart`: انتخاب از کل کاتالوگ، جستجوی سراسری، شمارنده و دکمه ادامه۴۰تایی؛ حذف سقف خاموش۴۰. کالای بدون رنج قابل انتخاب است و دلیل دارد؛ فقط کالای دارای آمار معتبر کارت نرخ و محاسبه هزینه نشان می‌دهد.
- `pubspec.yaml` و نسخه لاگر:۰.۶.۱+۸؛ dependency/lockfile، کلید امضا و package عوض نشده‌اند.
- `test/range_catalog_test.dart`:۱۰ آزمون جدید دامنه/DB/widget برای انواع کالا، نامعتبرها، عدم ادغام و عدم تغییر میانگین، dedup، غیرفعال و history-only،۱۲۵مدل، جستجوی فراتر از۴۰ و صفحه‌بندی واقعی تا۸۵.
- اسناد: درخواست، تغییرات، گزارش آزمون، README و بخش۵۵به‌بعد سند تولید؛ گزارش‌ها و ابزارهای بازتولید نسخه در `production/verification/v0.6.1/`.

## حفظ سازگاری
- همه اعلام‌های یکتا در۴۸ساعت، نه فقط آخرین نرخ یا یک رأی برای هر فروشنده؛ هیچ قیمت حدسی یا تبدیل مبهم واحد اضافه نشده است.
- ارقام، تاریخ و تومان فارسی، محاسبه همان کالا، بکاپ کامل ادغامی، history migration و فقط دکمه نوسازی بدون تغییر در قرارداد باقی‌اند.
- فهرست کامل محلی، نه پوشش تضمینی همه محصولات اینترنت. آمار منبع قدیمی یا نامعلوم به نام رنج روز نمایش داده نمی‌شود.
- آزمون گوشی واقعی/نصب upgrade با داده کاربر انجام نشده؛ این محدودیت جدا از آزمون خودکار و بررسی APK گزارش می‌شود.
