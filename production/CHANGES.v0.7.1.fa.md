# تغییرات۰.۷.۱+۱۰ نسبت به۰.۷.۰

- `range_task.dart` جدید: snapshot ساده، worker یک‌باره پس از تأیید، progress، kill/close، timeout/error/cancel terminal و آمار محاسبه‌شده قابل انتقال؛ بدون ارسال controller/DB/report سنگین بین isolateها.
- `range_page.dart`: حذف انتظار گزارش کامل همه خانواده‌ها، قطع restart بر اثر دریافت، کار فقط پس از تأیید؛ retry/لغو/پیشرفت/دلیل نبود آمار، پاک‌کردن نتیجه با شهر/مشخصه جدید و اعلان snapshot قدیمی هنگام داده تازه.
- `store.dart`: استخراج خواندن payload مشترک بدون حذف history/latest؛ API قدیمی rangeReport برای سازگاری و آزمون باقی است ولی پیش‌نیاز UI نیست.
- `city_scope.dart` جدید، MarketFilter و controller: یک شهر ماندگار با تمام نقش‌های صریح؛ cache قبلی فوراً پنهان. صف همه منابع فعال بدون شرط شهر باقی است.
- Info تنها selector شهر؛ پوشش یکسان دایرکتوری‌ها؛ حذف selector تکراری Prices و تفکیک لغو انتخاب‌گر از انتخاب همه شهرها؛ تاریخچه Chart، رنج و هزینه بازار مقید به همان scope؛ حسابگر دستی فقط برچسب scope می‌گیرد.
- AppLogger پیش‌فرض OFF، opt-in ذخیره‌شده و کلید Information؛ وقتی خاموش است record هیچ append ندارد. سقف۱MiB/۱۲۸KiB، حد۱۰نمونه و فقط محصول/منبع حفظ شد.
- یک منبع سازمانی جدید مشهد با۲endpoint احرازشده تلگرام/ایتای بنیان فولاد قوام؛ مجموع۷۴مسیر، canonical-dedup و نام فروشنده یکسان؛ نشانگر مهاجرت همه روشن۳ و حفظ opt-out بعدی.
- حذف خرید/دستمزد مشخص از نرخ فروش؛ باقی‌ماندن نامعلوم/قدیمی خارج آمار؛ نسخه About/اطلاعات اصلاح شد.
-۱۶آزمون جدید؛ به‌روزرسانی آزمون‌های برچسب/پیش‌فرض جدید، نه حذف assertion رفتار؛ smoke جداگانه SourceClient.
- بدون dependency/schema جدید؛ pubspec.lock، package، گواهی قبلی و دریافت فقط دستی ثابت‌اند.
- آرشیو فقط۴APK۰.۵/۰.۵.۱ طبق اجازه؛ بازیابی مستقل SHA و بایت‌برابر؛ بقیه تحویل‌های قدیمی حفظ شدند.

نتیجه واقعی ساخت/امضا در metadata، آزمون در گزارش نسخه و وضعیت پوش در تحویل بیرونی است. لاگ کاربر علت قطعی فریز رنج را اثبات نمی‌کرد؛ آزمون میزبان جای نصب روی گوشی نیست.
