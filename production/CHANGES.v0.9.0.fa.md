# تغییرات نسخهٔ ۰.۹.۰

## جستجو و زمان‌بندی

- اسکن پس‌زمینهٔ اختیاری با WorkManager و اتصال شبکه؛ بازه‌های قابل انتخاب ۱۵، ۳۰ و ۶۰ دقیقه‌اند. زمان اجرای دقیق را Android تضمین نمی‌کند.
- در هر اجرای پس‌زمینه حداکثر ۱۶ منبع فعال به ترتیب چرخشی و تا ۲ صفحهٔ عمومی از هر کانال خوانده می‌شوند. منابع عمومی سفارشی فقط اگر کاربر آن‌ها را فعال کرده باشد وارد چرخه می‌شوند.
- lease مشترک SQLite با مهلت ۳۰ دقیقه‌ای از هم‌زمانی نوسازی دستی و worker جلوگیری می‌کند و پس از مرگ فرایند منقضی می‌شود. وضعیت `busy` تا پایان پاک‌سازی و آزادسازی قفل فعال می‌ماند.
- صفحه‌بندی کانال‌ها سقف صریح دارد؛ حالت «همهٔ زمان‌ها» دیگر cutoff پنهان هفت‌روزه ندارد. در پنجرهٔ محدود، ردیف قدیمی‌تر از بازه برای snapshot تازه برگردانده نمی‌شود.

## حفظ داده و مرزها

- نسخهٔ schema به ۸ رسید؛ جدول lease افزوده می‌شود، بدون بازنویسی payload، تاریخچه یا تنظیمات دیگر.
- دادهٔ قدیمی در نوسازی ناموفق حفظ می‌شود؛ پیام‌ها و URLهای خصوصی، ورود به حساب و API حدسی استفاده نمی‌شوند.
- تحلیل پیام همچنان فارسی‌محور و مبتنی بر محصول/واحد/قیمت صریح است؛ متن نامرتبط به‌عنوان دادهٔ قیمت ذخیره نمی‌شود.

## فایل‌های Android و آزمون

- فایل ARM سی‌ودوبیتی: `IronPin-0.9.0-armeabi-v7a.apk`.
- فایل ARM شصت‌وچهاربیتی: `IronPin-0.9.0-arm64-v8a.apk`.
- هر دو فایل ساخته شدند و نسخه، معماری و امضای آن‌ها بررسی شد. هر APK فقط برای همان معماری است.
- `flutter analyze` بدون ایراد بود و هر ۳۶۸ آزمون موفق شدند.
- این APKها آزمایشی‌اند و با کلید انتشار صاحب برنامه امضا نشده‌اند. برای انتشار رسمی، با کلید اصلی برنامه امضا شوند. نصب روی گوشی واقعی آزمایش نشده است.
