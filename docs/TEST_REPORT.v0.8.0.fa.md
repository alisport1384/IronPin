- ۵ آزمون تازه در `test/window_v080_test.dart`:

     تغییر نمی‌دهد.
  2. ردیف با تاریخ اعلام خودش سنجیده می‌شود، سپس با زمان ذخیره.
  3. تب قیمت ردیف خارج از پنجره را نشان نمی‌دهد و با «همه زمان‌ها» برمی‌گردد.
  4. پاسخ رنج از پنجرهٔ زبانه استفاده می‌کند، نه ۴۸ ساعت پنهان.
  5. ردیف مبلغ‌دار بدون واحد اعلام‌شده همچنان با مبلغش کاندید است و «بی‌قیمت» شمرده نمی‌شود.
