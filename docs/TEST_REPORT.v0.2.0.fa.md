## آزمون‌های افزوده‌شده به ۷۸ مورد قبلی

- سایز/ضخامت/ابعاد/گرید قدیمی، ورق۸/۱۰، تیر۱۴/۱۶ و برند متفاوت.
- نگهداری تصمیم ماه شمسی، نگه‌داشتن داده، حذف فقط history قدیمی و عدم حذف latest/settings.
- مهاجرت فایل schema1 به schema2؛ حفظ تنظیمات منبع و خاموش‌ماندن انتخاب بعدی کاربر.
- batch با۱۲۰۰ ردیف، عدم تکثیر history و جلوگیری از downgrade.
- لاگ Markdown، ترتیب۲۵ رویداد موازی، خطای فایل، ارسال مسیرهای موجود و لغو انتخاب پوشه با mock.
- پوشش adapter شواهد برای همه کانال‌های تحقیق به‌جز تیک آهنِ احرازنشده؛ عدم تبدیل تاریخ پست/تصویر مشهد به قیمت تازه.
- فیلتر۸۰۰۰ ردیف،۴۰۰۰ نتیجه با ادامه timer اصلی و عدم پیروزی درخواست منسوخ؛ HTML حدود۴۰۲KiB/۳۰۰ردیف با timer اصلی.
- رابط انتخاب۶۰۰۰ پیشنهاد به صورت lazy؛ کمتر از۳۰ListTile ساخته‌شده، نه dropdown۶۰۰۰ردیفی.
- رابط ساده بدون چگالی، حفظ ورودی هنگام تعویض تب، ورق۱×۲×۲mm=۳۱٫۴kg و وزن اعلامی شاخه۱۵۵kg.

آخرین اجرای فشار میزبان: فیلتر۸۰۰۰ ردیف **۴۱۳ms** زمان سراسری داشت و timer اصلی **۳۷۷ بار** اجرا شد. این آزمون، کارکرد isolate را نشان می‌دهد؛ سنجه FPS/latency گوشی یا تضمین روانی روی همه مدل‌ها نیست. هیچ درصد بهبود نسبت به baseline ادعا نشده است.

## حفظ داده هنگام آپدیت

نام بسته و گواهی APK با0.1.0 برابر است؛ versionCode هر ABI افزایش یافته است: ARM64=2002، ARMv7=1002. نسخه متناسب با همان معماری نصب قبلی را **به صورت آپدیت و بدون حذف برنامه قبلی** نصب کنید. شرط امضا بررسی شده ولی نصب درجا روی دستگاه آزمایش نشده است. حذف اپ یا Clear data می‌تواند داده محلی را پاک کند.

گواهی SHA256: `360dabf5f2cf2ee39c9dc90bcb093a381e93a17d6a4f87d978a41d9ecff588b4`.

امضا آزمایشی AndroidDebug است، نه کلید انتشار عمومی مالک. هیچ کلید خصوصی/توکن در سورس قرار نگرفته است.

## لاگ و سند تولید

در برنامه: «اطلاعات ← لاگ Markdown و مسیر فایل‌ها ← ذخیره فایل‌های .md در پوشه دلخواه». فایل‌ها خودکار در حافظه اختصاصی برنامه نوشته می‌شوند؛ SAF کپی اختیاری به پوشه انتخابی است. پاک‌سازی ماهانه تاریخچه، فایل‌های لاگ را حذف نمی‌کند. فضای پر، خرابی فایل، توقف ناگهانی یا حذف برنامه می‌تواند روی ثبت/بقای لاگ اثر بگذارد.

سند قابل بازتولید: `production/PRODUCTION.fa.md`؛ تغییرات فایل‌به‌فایل: `production/CHANGES.v0.2.0.fa.md`؛ شواهد اجرا: `production/verification/`؛ قرارداد فرمول‌ها: `docs/CALCULATIONS.fa.md`؛ ممیزی کانال‌ها: `docs/CHANNELS.fa.md`.

## شکست‌های میانی و نحوه تفکیک آنها

- fixture اول مشهد پست تبلیغی بود؛ fixture دارای کپشن قیمت از داده واقعی جایگزین شد.
- تست widget به ترتیب صحیح pump/runAsync برای SQLite و شناسایی subclass دکمه نیاز داشت؛ پس از اصلاح خود آزمون، پاس شد.
- اجرای اول Gradle با تست هم‌زمان فشار RAM داشت و متوقف شد؛ اجرای بعد daemon disappeared داشت. AOT جدا سپس بسته‌بندی Gradle موفق شد. این شکست ساخت با خطای runtime اپ یکی نیست.
- اجرای اول smoke در TestWidgetsFlutterBinding با HTTP400 ساختگی خود تست روبه‌رو شد؛ هیچ شبکه‌ای انجام نشده بود. binding تست widget از smoke حذف شد و اجرای واقعی۱۲/۱۲ موفق شد. گزارش آن HTTP400 به شکست سایت نسبت داده نشده است.

## موارد آزموده‌نشده و حدود باقی‌مانده

۱. نصب/اجرای واقعی، SAF روی API21/Androidجدید، ورود واقعی ماه بعد و سنجش فریم گوشی کم‌حافظه.
۲. قیمت عددی روز فروشندگان مشهد از منابع تصویری/واحدنامشخص و استخراج تصویر خودکار.
۳. تضمین دسترسی شبکه گوشی، کانال خصوصی، همه کانال‌ها یا گردآوری دائمی هنگام بسته‌بودن اپ.
۴. GitHub Actions، commit یا push؛ هیچ‌کدام این نوبت انجام نشده‌اند.
