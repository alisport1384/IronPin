# IronPin | آیرون‌پین

اپلیکیشن اندروید فارسی، محلی و بدون سرور برای مشاهده قیمت آهن‌آلات، بررسی منشأ اعلام‌ها، رنج‌گیری بازار، تاریخچه واقعی و محاسبات وزن و هزینه.

## امکانات اصلی

- **قیمت‌ها و جستجوی ساختاری**: نمایش فشرده پیشنهادها با تفکیک سایز، ضخامت، ابعاد، گرید، واحد و شهر؛ تشخیص دقیق کالاهای فولادی (مانند «یک ورق آهن فولادی») و رد خودکار اقلام غیرفلزی و دارویی (مانند «قرص آهن یک ورق»). بهینه‌شده برای بارگذاری و پیمایش روان آرشیوهای بزرگ (۱۵٬۰۰۰ تا بیش از ۱۰۰٬۰۰۰ ردیف).
- **رنج‌گیری بازار**: محاسبه کمینه، بیشینه و میانگین اعلام‌های هم‌مشخصات و هم‌مبنا روی کاندیدهای دارای تاریخ و قیمت معتبر، همراه با حذف خودکار ادعاهای ناسازگار قیمتی.
- **نمودار محلی**: رسم روند پله‌ای تغییرات واقعی هر پیشنهاد ثبت‌شده روی دستگاه، بدون تولید داده یا گذشته ساختگی.
- **محاسبات وزن و هزینه**: ۱۵ گروه محاسباتی (ورق، میلگرد، تیرآهن، پروفیل، لوله، نبشی، ناودانی، تسمه، بولت/انکربولت و ...) در دو حالت ساده و پیشرفته.
- **دو هوش جستجوگر و OCR فارسی**:
  - **هوش جستجوگر ۱** (`lib/domain/searcher.dart`): استخراج ساختاری محصول، مبلغ، واحد، ارز و شهر از متن، جدول و تصویر لیست قیمت‌ها با OCR آفلاین فارسی/انگلیسی (Tesseract 5).
  - **هوش جستجوگر ۲** (`lib/domain/source_finder.dart`): پایش پیوسته صفحه‌های عمومی وب و شبکه‌ها برای یافتن منابع تازه و تحویل خودکار منابع معتبر به فهرست اتصال‌ها.
- **پشتیبان‌گیری و بازیابی کامل (JSONL)**: ذخیره و ادغام ایمن قیمت‌ها، تاریخچه، تنظیمات، منابع افزوده‌شده و وضعیت کامل هوش جستجوگر ۲ (فهرست‌ها، صف‌ها، نشانگرها و منابع پذیرفته‌شده/فعال).

## اصول داده و حریم خصوصی

- **بدون سرور میانی و بدون حساب کاربری**: تمام داده‌ها در پایگاه محلی SQLite روی دستگاه نگهداری می‌شوند و فقط مستقیماً از صفحه‌های عمومی منابع خوانده می‌شوند.
- **بدون حدس در قیمت و واحد**: ارز، واحد، شهر و مشخصات فنی در صورت نبود شاهد صریح حدس زده نمی‌شوند؛ فقط ریال صریح به تومان (`÷ ۱۰`) تبدیل می‌شود و وزن نظری ماشین‌حساب در رتبه‌بندی قیمت‌ها دخالت ندارد.
- **پوشش پیش‌فرض**: ۸۲ مسیر عمومی ثبت‌شده (سایت‌ها، تلگرام، ایتا، بله و روبیکا) به همراه امکان افزودن کانال عمومی و اسکن دوره‌ای اختیاری در پس‌زمینه (WorkManager با حداقل بازه ۱۵ دقیقه در اندروید).

## اجرا، آزمون و ساخت APK

پیش‌نیازها: **Flutter 3.24.5**، **Dart 3.5.4**، **JDK 17** و **Android SDK 35** (حداقل اندروید ۵.۰ / API 21).

```bash
flutter pub get
flutter analyze
flutter test

# ساخت جداگانه هر معماری (بدون --split-per-abi)
flutter build apk --release --target-platform android-arm     # ۳۲ بیتی (armeabi-v7a)
flutter build apk --release --target-platform android-arm64   # ۶۴ بیتی (arm64-v8a)
```

مسیر خروجی‌ها در `build/app/outputs/flutter-apk/` قرار می‌گیرد (`app-armeabi-v7a-release.apk` و `app-arm64-v8a-release.apk`). متغیرهای امضای انتشار (`IRONPIN_KEYSTORE` و کلیدهای وابسته) در `docs/BUILD.fa.md` شرح داده شده‌اند.

## ساختار پروژه و مستندات

```text
lib/domain/     مدل بازار، تحلیل متن، جستجوگر ۱ و ۲، رنج‌گیری و محاسبات خالص
lib/data/       پایگاه SQLite، بکاپ JSONL، مبدل منابع، کنترلر و زمان‌بند پس‌زمینه
lib/ui/         پنج تب فارسی (قیمت‌ها، نمودار، رنج‌گیری، محاسبات، اطلاعات)
assets/         فهرست منابع، شهرها، فونت وزیرمتن، داده‌های OCR و فرمول‌ها
test/           مجموعه کامل آزمون‌های آفلاین مدل، پارسر، بکاپ، مقیاس ۱۰۰هزارتایی و رابط
```
